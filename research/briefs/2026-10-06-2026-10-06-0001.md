# Brief: run 2026-10-06-0001, assembly-family alias screen (root 10, 12)

**What was tested and why.** Root 10 needs a task bank where a learned decoder has room to beat
fixed controls. The first bank (run 2247) failed because the hand-set grammar G already solved
its held-out cells quickly. The strategist asked for two task families that use the same
primitives but place addition differently, so a family-adapted decoder would have something
generic G lacks. Steward probes suggested the planned pair (gate vs branch addition) was
already dead. So this run screened a frozen set of 162 ten-token programs in six shapes over
{SUM, MAX, MIN} on three input domains, looking for any shorter (≤ 9-token) program that
matches ≥ 80% of each. It also timed search under U, F, G and G-marg on the surviving cells.

**What happened.** Clean run, 35 min, commit `a65ded0`. Outcome **row 1**: no eligible pair.

| Shape (cells) | Retained (625 / 1 331 / 2 401 inputs) |
|---|---|
| gate `(A+B)>0 ? C : D` (18) | 0 / 0 / 0 |
| branch-then `S>0 ? (X+Y) : Z` (27) | 0 / 0 / 0 |
| branch-else `S>0 ? Z : (X+Y)` (27) | 1 / 2 / 2 |
| post-addition `(S>0 ? X : Y) + Z` (54) | 4 / 8 / 8 |
| linear, two DUP placements (18 each) | 3 + 3 (by construction) |

A pair needs ≥ 4 cells per shape. The result is unchanged for any alias cutoff from 0.70 to
0.85. Search on the 16 cells left on 1 331 inputs used 50 paired seeds per cell × arm:
- G's median cost is 8–42k evaluations on the ten branch cells, 2–10× above the 4 096
  headroom line. F and G-marg are above that line on every cell.
- G is 8–11× faster than U and 1.5–6× faster than G-marg.
- One cell is hard for everything except G: U solves 8/50, G 42/50.

**What we learned.** At ten tokens there is room above G, so 2247's problem was the short
bank, not G. But on this alphabet most structural variants collapse into shorter programs.
Two mechanisms do it: ADD can be pulled out of an IF_GT branch using the zero constant, and
DUP can reuse the condition. Only post-addition survives in numbers. That is one family, not two.
