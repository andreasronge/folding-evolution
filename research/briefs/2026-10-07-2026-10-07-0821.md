# Brief: run 2026-10-07-0821 (question 18, slot 1; root 10 slot 11)

**What was tested and why.** Root 10's open question is whether selection can learn useful
decoder *context*, beyond tuning token frequencies. Two earlier procedures found no gain. This
run tried a compact one: a centred rank-one residual on G4's previous-token × next-token table.
From 16 saved 1723 token maps (8 BE, 8 PA), each start got two equally funded continuations on
shared seeds: T (token steps only) and C (token or context steps, half each). Each arm had 4 040
searches. A calibration stage first measured whether single context steps have repeatable,
selectable effects.

**What happened.** The run was clean: 174 964 searches in 2.6 h, all validation passed, and no
holdout was touched.
- Context versus token-only on fresh training searches: **C/T 0.955× [0.833, 1.095]**. A gain
  above about 1.10× is excluded for this procedure and budget.
- **Neither arm improved on its start:** T/S 1.03× [0.90, 1.16], C/S 0.98× [0.90, 1.07]. In-loop
  scores were flat for 20 generations, although parents were replaced 1.4 times per generation.
- Calibration: single context steps have real, repeatable effects (variance 0.047 [0.027,
  0.065] log2², comparable to token steps). Picking the best quarter of 24 mutants beats the
  average mutant on new seeds, but only gets back to parent level, because the average step
  hurts.
- Descriptively, in PA the learned residual looked slightly harmful (C/C0 0.91× [0.85, 0.98],
  8 pairs). The learned residuals bore no resemblance to the hand-set BE − PA context
  (|cos| ≤ 0.1).

**What we learned.** From already-tuned maps, this short 2 + 6 loop at 24 searches per child
made no resolved progress, for token steps as much as for context steps. So this null says
little about context itself. The comparison needs a loop that demonstrably climbs first.
