# Brief: run 2026-10-06-0811, contextual moves vs continued token learning (root 10, 13)

**What was tested and why.** Run 0132 found that learning 23 token multipliers on the hand-set
grammar G (the "M" maps) made fresh search about 2× faster on two withheld post-addition
compositions. The contextual learner never got going. The open question: does learning
*contextual* preferences add anything beyond token retuning? The run started from the six saved
M maps and continued each one twice, in two arms:
- **M+**: more token steps, nothing else.
- **R**: half token steps, half whole-row changes to the context table.

That gives 12 matched pairs × 35 generations. The run also scored frozen M against G on eight
cells outside the post-addition family.

**What happened.** Clean, complete run: 4 h 50 min, commit `0709104`, 12/12 pairs. Outcome
**row 4, unresolved**. Speed ratios (> 1 = first map faster), 95% intervals:

| contrast | fresh training | holdout (S?M:S)+M | holdout (S?M:S)+m |
|---|---|---|---|
| R / M+ | 1.00 [0.90, 1.11] | 1.16 [0.91, 1.48] | 1.06 [0.83, 1.31] |
| M+ / M | 1.45 [1.26, 1.69] | 1.21 [0.95, 1.54] | 1.43 [1.14, 1.78] |
| M / G (frozen, new seeds) | 2.08 [1.72, 2.49] | 2.25 [1.81, 2.81] | 2.06 [1.60, 2.63] |

- **Off-family:** frozen M / G is 2.23× [1.66, 3.06] on the two branch-else cells and 1.08×
  [0.72, 1.57] on the six linear cells.
- **Unregistered, six maps:** R / M+ is 1.33× on branch-else and 0.65× on linear. R also doubled
  post-addition solver supply over M+.
- **Selection:** children of every operator entered the next parent set at the chance rate
  (24–26% vs 25%).

**What we learned.** Every resolved gain is still token retuning of G's hand-supplied context:
- Allowing contextual moves gave no training gain over continued token learning. A gain above
  1.11× is excluded.
- On the withheld pair the extra gain from contextual moves is unresolved (points 1.06–1.16×).
- M's ~2× gain is not specific to post-addition among the branch shapes scored. With 200 seeds
  its holdout gains now clear 1.5×.

**Next and why.** No proposal; `next: strategy`. Strategy 0811 reserved root 10's last slot for
the strategist. My recommendation is a pre-registered off-family test of the existing learned
maps, with no new learning (about 1–2 h):
- The six "b" continuations, which never saw these cells, test whether R really shifts speed
  toward branch shapes and away from linear ones.
- The ablated maps show whether that shift needs the residuals.

Either answer finishes the root. If the shift holds, learned context is tied to the training
shape. If not, everything resolved is token retuning.

**Failures and uncertainty.**
- The spread between starting maps (0.41–0.45 log2) was twice the planned figure. That is why
  the holdouts stayed open. Settling a 1.16× effect would need about 20 independent starts;
  more seeds would not help.
- Before the run, the code review removed the stage-0 spread gate because it was unstable.
  The full run's calibration would have tripped it, so without that removal this study would
  not have run.
- One R trajectory (4a) was slow everywhere. It was kept in.
- The off-family pattern is post hoc. Linear cells sit near G's floor, and branch-else is not
  an independently trained family. One screened family, one optimizer, starts at M.
