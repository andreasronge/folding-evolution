# Brief: run 2026-10-12-0250: can an inherited bit learn which library suits a task family?

**What was tested and why.** Run 1736 showed that an inherited bit can learn *how often* to use a supplied library.
It learned only a dose. The strategist funded one test of whether inheritance can learn *which* content suits a
family.
- **Setup:** each program carries a bit. State 0 draws mutation donors from the saved order library, and state 1
  from the saved signed-gate library, each on half of mutations. The bit is redrawn with probability 1/32 toward
  50/50 and starts at 50/50.
- **Exposure:** populations evolve on six order cells or six gate cells (twelve 64-generation episodes). Arms:
  linked (L), bits shuffled (S), and neutral (N).
- **Readout:** the programs are thrown away. Each population's final mixture is deployed alone in fresh searches
  and compared with the 50/50 mix (M).
- **Scale:** 24 paired builds × 8 populations × 3 arms × 2 families. That is 1,152 exposures and 36,288 readout
  jobs, about 1.8 h of queue. Development cells only.

**What happened.**
- **The bit moved the right way, but not far.** On order, the final gate share was 0.377 against 0.485 shuffled
  (−0.11 [−0.16, −0.06], 22/24 builds). On gate it was +0.03 [−0.03, +0.10], unresolved.
- **No saving: R = 0.991 [0.926, 1.060]** (matched mixture / 50/50 mix, averaged over both families). Order 0.98,
  gate 1.00. The pre-set rule says "20% pooled saving excluded"; the interval actually excludes savings above about
  7%.
- **The test had room to succeed.** The matched pure library costs 0.73× (order) and 0.78× (gate) of the mix.
- **Mechanism (descriptive, this run):** the bit is selected almost only before the first solve in each episode.
  After that, the redraw toward 50/50 pulls it back. Order populations reached about 0.24 at first solve, but the
  readout froze about 0.38. The cost of each frozen law is what its frequency predicts. Linkage added nothing visible,
  and L was not resolved cheaper than S or N.
- All 36,288 jobs ran. 19 were capped. All audits passed. My forecast (R ≈ 0.85–0.9) was too optimistic.

**What we learned.** Under this rule, program-linked inheritance detects which supplied library suits a family on
one of two families, but it holds only a weak preference, because selection stops acting once a solver exists. The
frozen choice is worth nothing measurable, while simply using the matched library by hand saves 22–27%. Across 1736
and 0250, inheritance has found the direction of a supplied law but always freezes less than the obvious hand
setting.
