# Brief: run 2026-10-05-1814, which part of the "no-lift" vector speeds evolution? (09)

**What was tested and why.** In run 1705, the *other* family's fitted op vector (X) gave no
sampling lift on the held-out threshold, yet reached an exact solve 3.3× (sum>2) and 1.9×
(max>2) sooner than uniform. That was unregistered and used only 50 pairs. This run split X
into two parts. IG raises only INPUT and GT to X's values and thins the rest evenly. R keeps
INPUT/GT uniform and uses X's shape for the other 20 ops. The question was whether either
part alone gets within 1.5× of X, in both tasks. It also replicated U vs X on fresh seeds.
Pre-registered, 250 paired seeds per cell, one look.

**What happened.** 2,000 runs in 60 min, complete; all 1,953 solvers re-verified exact.

| Median evaluations, ratio (99.5% CI) | sum>2 | max>2 |
|---|---|---|
| uniform ÷ X (replication) | **2.73** (2.12–3.48) | **2.02** (1.45–2.46) |
| IG ÷ X | 1.29 (0.92–1.63) | **0.90** (0.71–1.08) |
| R ÷ X | 1.69 (1.39–2.20) | 2.16 (1.57–2.78) |
| uniform ÷ IG / uniform ÷ R | 2.11 / 1.61 | 2.24 / 0.93 |
| Exact solvers per 125M tapes, ÷ uniform: IG / R / X | 3.2 / 0.23 / 1.02 | 3.9 / 0.35 / 1.33 |

- max>2: IG carries the speed-up. R shows no gain and leaves 30 of 250 runs unsolved
  (uniform 5).
- sum>2: both parts beat uniform, but neither is resolved against the 1.5× margin. Both
  are near misses.
- The tasks disagree, so the frozen rule parks 09.

**What we learned.** The 1705 speed-up is real. X's "no sampling lift" was a cancellation:
INPUT/GT alone makes exact solvers 3–4× more common, and the rest of the vector makes them
3–4× rarer. So on max>2 the part that speeds evolution also raises supply. The only speed-up
*against* supply left is R on sum>2 (1.61× faster with a quarter of the solvers). There, R
and X meet about 10× more training-perfect but inexact programs. max>2, which fits most sum>2
training sets, is a plausible stepping stone, but this run did not test that.
