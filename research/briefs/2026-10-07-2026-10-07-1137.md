# Brief: run 2026-10-07-1137 (question 19, slot 1; root 10 slot 12)

**What was tested and why.** 0821's context test had no working control: token-only
continuation from the 16 saved 1723 maps did not learn, so its context null meant little. This
run kept the starts, cells and operators. It changed only how much evidence scores each
candidate: 96 searches per candidate instead of 24, with 12 generations and 9 600 searches per
trajectory. Stage 1 ran token-only continuation (T) and passed a code gate if T/S was at least
1.10× on 0821's fresh seeds. Stage 2 then ran context continuation (C: token or rank-one context
step, half each) on the same seeds. S, T, C and C0 (C with its residual removed) were scored on
a new seed block.

**What happened.** The run was clean. It made 335 700 searches in 4.6 h, all validation
passed, 0821's start scores reproduced bit-identically, and no holdout was touched.
- **Token continuation learned.** T/S was **1.143× [1.089, 1.200]**, with all 16 starts
  improving. The gate passed, and on new seeds T/S was **1.122× [1.031, 1.222]**. 0821's maps
  from the same starts were 1.03× [0.90, 1.17].
- **Context added nothing resolved:** C/T **0.967× [0.871, 1.073]** (outcome row 6). C's token
  part lagged T's, at C0/T 0.932× [0.860, 1.010]. Half of C's steps went to context.
- Per-start gains correlate only 0.15 between the two seed blocks, so only the pooled numbers
  mean anything.

**What we learned.** More reliable scoring per candidate turned a loop that did not move into
one that improves already-tuned maps by about 1.13×. In that loop, rank-one context mixed in
under equal search funding gives no resolved benefit, and a mean gain above about 1.07× is
excluded. That makes four contextual procedures with no resolved gain beyond token learning.
