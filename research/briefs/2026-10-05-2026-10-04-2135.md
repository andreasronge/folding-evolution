# Brief: run 2026-10-04-2135, shared arrival

**What was tested and why.** Under self-mating, a seeded shared form establishes (06). Yet
random-start runs still almost never end shared. Is that because variation rarely produces
exact shared children (arrival), or because a single new copy rarely takes hold
(establishment)? We used the 50 saved §32 J final populations (self-mate, crossover 0.3,
L 64) in two stages:
1. An offspring census through the engine's own lexicase reproduction: 174M children, 30M of
   them from partly-shared parents.
2. 100 naturally produced shared children, each put back as one copy into its own population
   and run 500 generations, with matched no-insertion controls.

**What happened.**
- **Arrival:** 56 new exact shared children in the 16 target populations (1.6e-6 per child,
  12 of 15 populations with ≥ 1). That is about 2 per run over the non-shared phase
  (per run 0–7).
- **Kind:** 44 A-only, 12 other, **0 B-helper**, yet both runs that ended shared are B-helper.
  B-helper arrival is ≤ 1.2e-7 per child.
- **Establishment:** 0 of 100 single copies established (≤ 3.6%); all were gone by
  generation 30. Controls showed spontaneous shared individuals in 35 of 100 runs, all lost.
- **Consistency:** ~32 arrivals × ≤ 3.6% ≤ ~1.2 expected replacements; 1 was observed. This
  is consistent, but explains nothing.

**What we learned.** "Shared helpers are rare because they never arrive" is wrong: shared
children turn up a couple of times per run and drift out like any single copy. The form that
actually wins (B-helper) never arrived at all. So the sharper, untested story is that
A-only copies arrive and die, while B-helper rarely arrives and wins when it does.
