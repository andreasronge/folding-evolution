**Current line and mechanistically different candidates.** I searched the literature
for this review. [Keijzer, Ryan and Cattolico, *Run Transferable Libraries* (2004)](https://www.cs.york.ac.uk/rts/docs/GECCO_2004/Conference%20proceedings/papers/3103/31030531.pdf)
passes learned functions between GP runs. It is the closest precedent for our frozen
repertoire, although literal insertion windows are a narrower representation.
[Rosca, *Towards Automatic Discovery of Building Blocks in Genetic Programming*
(1995)](https://cdn.aaai.org/Symposia/Fall/1995/FS-95-01/FS95-01-011.pdf)
uses parent–offspring fitness changes and block activation to create subroutines during
search. That motivates examining unfinished population material rather than requiring
complete solver corpora. The proposed first stage is still external extraction; simply
moving it inside a loop would not make the map individually inherited.

The owner's **inherited modifiers** are a different credit mechanism: useful offspring
can propagate their parent's variation law without an external fitting objective.
[Stephens et al., *Self-adaptation in evolving systems* (1998)](https://pubmed.ncbi.nlm.nih.gov/9847423/)
studies encoded mutation/crossover probabilities and their indirect selection. It
motivates this alternative, not success for our token modifiers. Root 23 bounded one
instance. Another mutation-scale trial currently has less evidential support than using
the existing early-program signal with the newly useful fragment representation.

A second serious alternative is **suffix-preserving local mutation without a new
library**. W helps across every bank, and random recoding hurt Q. A repaired point-edit
path could test whether protecting the decoded suffix recovers W's gain. This changes
variation geometry rather than acquiring repertoire content. It is a credible 3–4-hour
study, but less directly addresses the acquisition gap; W/C still bundles locality and
content. The post-hoc negative correlation between F/W and W/C is not sufficient evidence
that they substitute: both ratios contain W, which can itself induce negative association.

**Cost interpretation matters.** The latest analysis divides the 48,039 worker-second
solver corpus by F's roughly 0.5 worker-second saving over W to get about 96,000 searches.
That is a gross illustration, **not incremental F-versus-W repayment**: both procedures
use C fitted from the same corpus. W is library-free, not acquisition-free. Existing F
extraction cost about four worker-seconds across the sixteen libraries. Conversely, a
new partial collection costs extra if exact C is retained. From 1831's saved timing
records, its sixteen partial collections cost 5,058 worker-seconds and 521 wall-seconds;
these are historical procedure costs, not a price for the new extractor. Separate
incremental library costs from a complete from-scratch pipeline. Stage one cannot claim
cheap end-to-end acquisition; the conditional second stage removes exact C and charges
each pipeline's own acquisition and arithmetic mean search costs.
