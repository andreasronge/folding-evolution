2. **note — This is the right next intervention.** Conditional-uniform inverse encoding preserves the complete ordered token population while changing the ongoing decoder. The existing decoder's positive intervals and separate random streams make this implementable. Together, the four arms can distinguish learned-start sufficiency, ongoing-decoder sufficiency, combined dependence and redundancy on these three targets. No clearly cheaper design answers all four possibilities: dropping either mixed arm loses the interaction; switching tables on unchanged alleles confounds initialization; new learning adds cost without isolating this mechanism. Keep the stated scope: an ongoing effect includes inherited latent alleles, mutation, crossover and continued program supply, not specifically improved neighbourhoods beyond sampling.

3. **note — Preserve shared-seed dependence in every contrast.** Removing GG from P1/P2 does not make maps independent with respect to search noise: all maps still share cases, source alleles, variation, selection and re-encoding streams. Likewise, adding GG's variance to a map variance does not generally recover the covariance terms of a paired ratio. In plan.md, specify an interval calculation retaining whole seed blocks across arms and maps, and the fixed equal BE/PA weighting—for example, a crossed map/seed bootstrap with maps resampled within training family and seed blocks shared across all maps/cells. Report the proposed map-level t interval as a sensitivity check if useful. Do not let the 200-seed fallback inherit the 400-seed precision claim without recalculation. This is an analysis refinement, not a reason to redesign the grid.

State these conditional conclusions in the headings and use I_G, O_G and the interaction to describe contributions. These are interpretation notes; the measurements already needed are present.
