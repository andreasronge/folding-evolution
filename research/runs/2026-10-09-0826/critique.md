The experiment is worth running, but its stopping rule turns an unresolved control comparison into a mechanism conclusion and could terminate a useful fragment operator prematurely.

1. **blocking — Fix the unresolved-control branch.** “F/C resolved > 1 while F/W is not” does not establish that “block editing explains it.” For example, F/C = 1.20 [1.08, 1.33] and F/W = 1.15 [0.96, 1.38] would trigger closure despite a plausible substantial fragment-specific benefit. Route this outcome to **unresolved joint-content contribution**, with its resolution price. The existing F/C upper bound < 1.10 can still end this extractor on practical grounds. If abandoning it merely because the evidence is insufficient is the intended investment decision, distinguish that from evidence for the block-editing explanation. No equivalence test is needed unless equality is actually needed for the decision.

2. **note — Baseline feasibility is credible; the new-arm price remains conditional.** I checked the 1246 raw rows: C solved 936/1,024 (91.4%), averaging 5.468 worker-s/search. At that rate the proposed 2,048 C searches should yield about 1,872 solves; 8,192 searches at 1.2× that runtime cost about 53.8k worker-s, or 90 min at ideal ten-worker throughput. However, historical capped C searches averaged 28.9 s. If the three block arms mostly cap, the same arithmetic approaches six hours, before extra diagnostics. Neither B's incoherent blocks nor F's new operator has a measured solve rate. In plan.md make the promised prepare smoke an explicit admission decision using measured arm-specific throughput and difficulty, including diagnostics; do not admit an unaffordable roster just because the timeout is three hours. Report expected solve counts for each arm and the complete reuse price, including agent/build time. Preserve a complete, balanced corpus roster if preparation requires redesign.

3. **note — Freeze extraction and implementation edge cases before efficacy scoring.** The probe establishes 1,808 source solvers and recurring windows, but not the 64 leave-one-cell-out libraries after all exclusions. State deterministic final tie-breaking, short/empty-library behavior, length sampling shared by F/B/W, and which cells the whole-solver exclusion consults. An empty library is a feasibility outcome, not grounds to silently drop a corpus. Verify that decoding after replacement changes only the intended window, preserves the following token and suffix, and handles the end of the tape. Independent operator RNG preserves the existing random draws, not identical selected parents after trajectories diverge. Clarify the “+20% edit volume” estimate: r = 0.2 is a child fraction, not a measured token-change increase.

4. **note — This tests a useful procedure, with a narrower mechanism interpretation.** Knockout activity on 96 inputs shows contribution in source-program context; it does not certify a self-contained computation or usefulness at arbitrary insertion stacks. Report wrong-type/default behavior as well as underflow, and retain source provenance. F/B removes cross-position dependence in the library draw, but equal proposed token marginals and spans need not match realized token changes or computational validity. F/W also changes token supply. A three-way win therefore supports the learned block procedure beyond these controls, not isolated modularity or an explanation of C's existing advantage. Leave-one-cell-out excludes direct extraction from the scored cell, not all shared solution pieces or in-sample information in C. Keep the development-bank scope; any later fresh-transfer claim needs a fresh bank frozen with the method.

5. **note — Worth this bounded run; prior-work framing is appropriate.** [Run Transferable Libraries](https://www.cs.york.ac.uk/rts/docs/GECCO_2004/Conference%20proceedings/papers/3103/31030531.pdf) is the closest named technique; [ARL](https://cdn.aaai.org/Symposia/Fall/1995/FS-95-01/FS95-01-011.pdf) and [DreamCoder](https://arxiv.org/abs/2006.08381) are relevant broader precedents. The contribution is a controlled stack-tape mechanism test against a strong fitted decoder, not a new library-learning principle. It can change which representation is worth acquiring, though it does not test evolutionary acquisition. Compared with another C/T fresh-shape replication, that decision is more immediate. No clearly superior cheaper full design is established: dropping B or W loses a distinct control. The cheaper first action is the already proposed extraction/timing stage. Justify 32 seeds using a precision scenario: the earlier 1246 corpus log-ratio SD of 0.21 gives a roughly ×1.12 interval half-width at n = 16, informative but not automatically decisive for a 1.15× target, and it is not a measured variance for these new contrasts. A broad F/C interval spanning no gain and useful gain, or a C win with unresolved F/B or F/W, would leave the key investment or mechanism question unsettled; report that rather than a negative result.
