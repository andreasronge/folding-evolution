The 2.8 h all-capped estimate leaves little room for slower decoding. The 5–7 h full-cycle allowance is plausible with the narrow extension and existing replays.

2. **note — Q failure is not a verdict against P.** Keep C/Q as the primary comparison, but replace “the acquisition target must carry conditional structure” with “this G4-based positional replacement is insufficient.” Read C/P regardless of C/Q's outcome. If Q fails while P meets the sufficiency bound, independent positional supply remains a viable target; do not deprioritise it. If Q succeeds but P fails, supplied grammar remains useful. If both fail, these two replacements failed under the fixed operators; that favours investigating dependencies without proving that every positional learner must fail. This is an interpretation correction using already-planned measurements, not a request for more arms or tests. Neither success demonstrates learnability, and the changed variation neighbourhood prevents attributing a failure solely to solver supply.

3. **note — Validate the actual intervention.** The proposed quantized propagation, start-row identity and legacy replays are appropriate. A per-token tolerance alone can conceal distributed mismatch. Check the positional lookup against a simple reference decoder at every position; repeated-K replays do not by themselves exercise changing tables. Freeze fitting, support handling and hashes before target scoring. No target-performance tuning of the projections.

4. **note — Worth this run; the closest techniques are named appropriately.** PBIL is a useful precedent for P's independent positional probabilities, PIPE for program-position distributions, and EDP for conditional program models. C's nearest listed analogue is [N-gram GP](https://drops.dagstuhl.de/entities/document/10.4230/DagSemProc.08051.5), which used instruction triples; C uses a bigram. These are externally fitted, frozen replacements inside evolutionary search, not a new EDA learning algorithm. The contribution is the controlled replacement result. No missing closer precedent changes that assessment. Against the [11–16 h executable-fragment alternative](../../plans/learned-executable-fragments.md), this 5–7 h test can identify a sufficient positional target before paying for extraction and new operators. A start-row-only control would be cheaper but a failure would leave the remaining positions unresolved. Dropping P would save searches while losing the decisive interpretation in point 2. I see no clearly cheaper design answering both questions.
