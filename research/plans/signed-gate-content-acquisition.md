# Can the frozen library recipe acquire useful conditional-value content?

Concept plan for [root 10](../questions/10-compositional-map-transfer/question.md),
funded by [strategy 1938](../runs/2026-10-11-1938/strategy.md). One full
experiment followed by strategy review. The steward supplies the proposal,
fixed sample size and primary decision rule. This is a direction and cost
envelope, not an experiment registration.

The question is whether the unchanged uncapped semantic extractor acquires
useful bias from a different computation family and helps on excluded
combinations. Order reuse now has held-out and intervention evidence. The
rectifier probe found little emittable recurrent content in its sources;
it did not settle portability of the recipe. Another order ablation cannot
settle that gap. This candidate uses smaller conditional computations and
shorter destinations, with the existing language and executor.

**One candidate bank.** Keep `v2_x4`, D625 (four independent integers over
−2..2), the tree grammar and 32 compiled-token limit. For ordered distinct
indices a,b, define expanded ordinary expressions:

- `p(a,b) = Xa > 0 ? Xb : 0`;
- `n(a,b) = Xa > 0 ? 0 : Xb`.

These 24 helpers gate one value by a different input's sign. They neither
select min/max nor rectify their own pair sum. Each has four tree nodes and
six compiled tokens: IF_GT already tests positivity. They are specifications
for labels and a supplied comparator, never extra primitives or learned seeds.

Sources are `p/n(a,b) + (Xc+Xc)`, with c outside {a,b}: 48 candidates and
two source contexts per helper. Write doubling as ADD, not a new multiplication
instruction. Source canonicals have eight nodes and twelve compiled tokens.
Destinations are `p(a,b)+n(c,d)`, with all four indices distinct: 24 candidates,
nine nodes and thirteen compiled tokens. Disjoint pairs avoid the simple
same-condition collapse. Doubling separates source outputs from destinations
while providing recurrence opportunities; it may also teach irrelevant doubled
inputs. Neither canonical recurrence nor these size counts guarantee that
evolved solvers expose the intended helper as a proper subtree.

The [label-only audit](../runs/2026-10-11-1938/signed-gate-planning-audit.json)
found 48 distinct source and 24 distinct destination behaviours. Maximum
source/destination agreement is 24%; maximum between distinct destinations
61.6%. Against 960 distinct saved behaviours from DG, TS, gate-sum, order and
rectifier banks, maxima are 31.2% for sources and 56.8% for destinations.
No evolutionary search, short-program enumeration, compiler check or timing
ran. This establishes semantic room, not an admitted bank or useful headroom.

Retain eligible sources by a deterministic semantic rule, checking remaining

**One complete experiment.** Acquire independent libraries under ordinary
R-tree, starting from the same fixed two-attempts-per-source policy as 1228.
With all sources admitted that is 96 attempts per build, twice the order
source roster; charge it explicitly, including failures and empty libraries.
Freeze this policy before new efficacy observations.

Compare new R-all, ordinary R-tree, the 24 saved order R-all libraries transported
unchanged, and a supplied R-gate prior containing all 24 expanded p/n helpers
uniformly. All use the same donor mix and search limits. R-gate is family-informed
human knowledge, receives no whole destination solution and pays full primitive
size. The transport reference asks whether acquiring this family buys anything
beyond already available bias. It is not a matched-content causal control.

The primary question is useful new R-all versus R-tree on the protected roster.
The steward should choose a material capped arithmetic-cost reduction and a
fixed size with a 95% interval; a 20% reduction is a pricing scenario, not a
registered threshold. Preserve independent-build uncertainty, fresh paired
searches, all cells, failures and solve counts. Keep both other comparators
visible: a generic improvement shared with transported content does not show
a need for new acquisition; loss to R-gate limits practical value.

Inspect the source census: exact yield, proper helper occurrence, emittable
representatives, recurrence, library retention, other recurrent computations
and destination coverage. This is diagnostic, not a universal ≥25% helper
admission gate. Do not discard helper-poor builds or require a pilot efficacy
win before confirmation. Missing named helpers need not mean no useful bias.
If every library is empty, its declared fallback already identifies the
procedure as R-tree; report that degeneracy rather than duplicating identical
scoring. Other early exits concern validity, precision or complete cost.

There is no spare probe allowance now. Bounded correctness, screening and
source/development timing belong to preparation of this substantive comparison;
an open-ended efficacy pilot cannot be relabelled a full experiment. If only
such a pilot can be justified, return to strategy without running it. Use
historical variation and conservative scenarios for pricing; never use protected
performance to choose size, library settings or tasks. If ordinary first-attempt
solving exceeds about 90% on development tasks, surface question 50's condition
and price the possible library harm before admission. Do not silently add a gate.

Use sustained source/development rates, verifier tails, extraction costs and

That example is not an adequate-size assertion. Return if an informative

Report acquisition plus repeated-search cost `A + N*S`, with uncertainty,
in arithmetic evaluations and comparable worker time. Charge one complete
acquisition per deployed build. Show transported-library costs both when
already owned and when newly acquired. A supplied prior has no evolutionary
acquisition, but its construction cost and supplied knowledge remain explicit.
No assumed deployment horizon or uncapped time-to-solution claim.

A material protected saving would extend the frozen acquisition recipe to
this second conditional-content family. A useful advantage over transported
order content strengthens the case for new acquisition, without isolating
helper causality or establishing symmetric family specificity. A bounded small
effect or harm limits this source/recipe pair; broad uncertainty needs a
resolving price. None establishes inherited content discovery. Return to
strategy after the answer or an earlier obstacle. No automatic extra bank,
source redesign, helper ablation or new engine follows.

The closest precedent found in this review is [Keijzer, Ryan and Cattolico,
*Run Transferable Libraries—Learning Functional Bias in Problem Domains*
(2004)](https://www.cs.york.ac.uk/rts/docs/GECCO_2004/Conference%20proceedings/papers/3103/31030531.pdf).
Our frozen external extraction supplies expanded mutation donors. The alternative
[Bowers et al., *Top-Down Synthesis for Library Learning* (POPL 2023)](https://arxiv.org/abs/2211.16605)
synthesizes abstractions from a corpus for compression. This study asks whether
the existing representation generalizes before buying that different learner;
neither paper predicts this bank's performance.
